SCREENSHOT 3: post-book.png
================================================================================
Description: Add a new book to the database.
Save as: screenshots/post-book.png

[In Postman]:
- Method: POST
- URL: http://localhost:3000/books/
- Headers:
    Content-Type: application/json
- Body -> Select "raw" -> Select "JSON":
{
  "title": "Clean Code",
  "author": "Robert C. Martin",
  "price": 550,
  "pages": 464
}

[In Terminal (cURL)]:
curl -X POST http://localhost:3000/books/ -H "Content-Type: application/json" -d "{\"title\":\"Clean Code\",\"author\":\"Robert C. Martin\",\"price\":550,\"pages\":464}"

What to capture in screenshot:
- Status Code: 201 Created
- Response Body:
  {
    "message": "Book created successfully",
    "bookId": 11,
    "book": { ... }
  }
